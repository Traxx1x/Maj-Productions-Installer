# MajProductions Launcher

Download the latest launcher for Windows 10/11:
**[MajProductions-Setup.exe](https://github.com/Traxx1x/Maj-Productions-Installer/releases/latest/download/MajProductions-Setup.exe)**

The installer lets you choose the install folder, a desktop shortcut and whether the launcher starts with Windows.
Uninstall any time from Windows Settings → Apps.

**"Windows protected your PC"?** The installer isn't code-signed yet, so Windows SmartScreen may show this the first time.
Click **More info → Run anyway**. Only download the installer from this page or the MajProductions website.

This repository only hosts the installer downloads.
